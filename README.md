# LUMISTAR · AI 产品经理作品集

蔡泽萍的个人求职作品，包含项目经历、LUMISTAR 公开产品研究与 AI Coach 静态流程示意。

- 在线访问：https://echogithu.github.io/lumistar-ai-product-portfolio/
- 纯 HTML、CSS、JavaScript，无构建和安装依赖。
- 本地查看：用浏览器打开 index.html。

## 文件

- index.html：页面内容、研究底稿与静态方案示意。
- style.css：全局样式与响应式布局。
- report.js：导航、产品轮播、滚轮切换与底稿弹层。
- assets/：产品图片、演示帧、图标与素材来源。
- resume.pdf：个人简历文件；页面下载入口暂时隐藏。

## 部署

GitHub Pages 使用 main 分支根目录发布；.nojekyll 使文件直接按静态站点提供。
修改后提交并推送到 main，Pages 会重新部署。

## 展示边界

本作品为个人求职展示，非 LUMISTAR 官方站点。AI Coach 为静态流程示意，未连接真实设备；55% 为示例基线，下一次训练待完成，效果待验证。
公司研究、产品规格与价格的来源及口径见页面“研究底稿”；图片来源见 assets/sources.json，图标许可见 assets/heroicons-LICENSE.txt。

原始设计记录、历史预览和模块地图仅保留在本地副本，不纳入发布仓库。
